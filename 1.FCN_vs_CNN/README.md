# 컴퓨터 비전 학습 자료

컴퓨터 비전과 딥러닝 실습 자료입니다. PyTorch로 모델을 직접 학습하고 결과를 비교하며, 모델의 구조와 동작을 이해하는 것을 목표로 합니다.

첫 번째 주제는 **MNIST 손글씨 분류를 통한 완전연결 신경망(FCN)과 합성곱 신경망(CNN) 비교**입니다. 데이터 확인부터 모델 정의, 학습, 평가, 추론까지 실습하고, 이미지 위치를 바꾸었을 때 두 모델의 예측이 어떻게 달라지는지 살펴봅니다.

## 학습 자료

- [1. FCN과 CNN 비교](1.FCN_vs_CNN/): 같은 데이터와 학습 설정으로 두 모델의 구조, 파라미터 수, 분류 성능을 비교합니다.
  - [FCN.ipynb](1.FCN_vs_CNN/FCN.ipynb): 완전연결 신경망 실습
  - [CNN.ipynb](1.FCN_vs_CNN/CNN.ipynb): 합성곱 신경망 실습

## 실행 방법

Python 3.12 환경에서 프로젝트 폴더를 열고 가상환경을 준비합니다.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

VS Code의 Jupyter 확장에서 각 노트북을 열고, 커널로 프로젝트의 `.venv/bin/python`을 선택한 뒤 처음부터 실행합니다.
노트북의 작업 디렉터리는 `1.FCN_vs_CNN/` 폴더로 설정합니다. MNIST는 첫 번째 셀에서 작업 디렉터리의 부모에 있는 `data/`, 즉 프로젝트 루트의 `data/`로 다운로드됩니다.

## 노트북 구성

| 셀 | 내용 |
|---|---|
| 1 | MNIST 다운로드 |
| 2 | PIL 이미지와 정답 확인 |
| 3 | FCN 또는 CNN 모델 정의 |
| 4 | 학습 가능한 파라미터 수 확인 |
| 5 | 학습 및 테스트 손실·정확도 확인 |
| 6 | 추론 데이터 준비 |
| 7 | 선택한 테스트 이미지 추론 |
| 8 | 같은 이미지를 네 대각선 방향으로 이동시킨 후 추론 |

- `FCN.ipynb`: 784 → 128 → 64 → 10 완전연결 신경망
- `CNN.ipynb`: 1 → 8 → 16 채널의 합성곱·풀링 블록과 분류기
- 공통 설정: 5에포크, 배치 크기 128, Adam 학습률 0.001, 시드 42
- CUDA를 사용할 수 있으면 GPU, 그 외에는 CPU에서 실행합니다.

추론할 이미지는 7번 셀의 `sample_index`, 이동량은 마지막 셀의 `shift_pixels`로 바꿀 수 있습니다.
커널을 재시작하면 학습된 가중치가 초기화되므로 추론 전에 학습 셀을 다시 실행합니다.
한 이미지의 예측 확률 및 이동 결과와 전체 테스트 정확도는 구분해서 비교합니다.

가상환경과 다운로드한 데이터는 저장소에 포함하지 않습니다.
